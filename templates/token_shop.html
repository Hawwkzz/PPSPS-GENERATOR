Questions fréquentes

Combien coûte une génération de PPSPS ?

Chaque génération coûte 50€. Vous payez uniquement quand vous générez un document.

Comment fonctionne le paiement ?

Vous achetez 1 jeton pour 50€ via Stripe. Le jeton est consommé lors de la génération du PPSPS. Si la génération échoue, le jeton est automatiquement remboursé.

Les jetons expirent-ils ?

Non, vos jetons n'expirent jamais. Utilisez-les quand vous en avez besoin.

Puis-je obtenir un remboursement ?

Si la génération échoue pour une raison technique, le jeton est automatiquement remboursé sur votre compte. Pour tout autre cas, contactez le support.

Le paiement est-il sécurisé ?

Oui, nous utilisons Stripe, une plateforme de paiement sécurisée et certifiée PCI DSS niveau 1. Nous ne stockons aucune donnée bancaire.

Actuellement, vous devez acheter les jetons un par un. Cela vous permet de payer uniquement pour ce dont vous avez besoin.
